# Benefit illustrations

Generated with the built-in image generation tool (imagegen skill).
Style reference: `public/images/contact-illustration-v2.png`.
Consumer: `app/components/CareAdvantages.vue`.

## Design decisions

Four compact object illustrations reinforce the four benefits, with a consistent camera, material palette and lighting. Copy remains HTML, always visible. Images have empty alt text because their meaning is already expressed by the adjacent heading and paragraph. The office is a symbolic model, not a depiction of the actual premises; documents have no invented certifications or seals.

Desktop: four columns with images above aligned copy. Tablet: two columns. Mobile: one column with small images beside copy. No carousel, hidden information or decorative motion.

References:
- https://www.nngroup.com/articles/7-tips-memorable-imagery/
- https://www.w3.org/WAI/tutorials/images/decorative/
